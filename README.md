# 🐍 Revisão e Estudos de Python

Este repositório foi criado para centralizar meus códigos, anotações e exercícios durante o meu processo de **reestudo da linguagem Python**. O objetivo principal é consolidar conceitos fundamentais e avançados, servindo como um guia prático de referência rápida.

## 🎯 Objetivos
* **Relembrar a sintaxe** básica e as melhores práticas da linguagem.
* **Praticar lógica de programação** com exercícios e pequenos projetos.
* **Documentar a evolução** dos estudos para consultas futuras.

---

## 📂 Estrutura do Repositório

O projeto está organizado por tópicos de aprendizado:

* **`01-fundamentos/`**: Variáveis, tipos de dados (strings, ints, floats), operadores aritméticos e lógicos.
* **`02-estruturas-de-controle/`**: Condicionais (`if`, `elif`, `else`) e laços de repetição (`for`, `while`).
* **`03-estruturas-de-dados/`**: Listas, tuplas, dicionários e conjuntos (sets).
* **`04-funcoes/`**: Definição de funções, parâmetros, escopo e funções lambda.
* **`05-orientacao-a-objetos/`**: Classes, objetos, métodos, herança e polimorfismo.
* **`06-modulos-e-pacotes/`**: Importação de bibliotecas padrão e instalação de pacotes externos (pip).
* **`07-projetos-praticos/`**: Pequenos scripts e desafios desenvolvidos para fixação.

## 🚀 Como executar os códigos

1. Certifique-se de ter o Python instalado em sua máquina.
2. Clone este repositório:
   ```bash
   git clone https://github.com
   ```
3. Navegue até a pasta do arquivo que deseja testar:
   ```bash
   cd 01-fundamentos
   ```
4. Execute o arquivo:
   ```bash
   python nome_do_arquivo.py
   ```
